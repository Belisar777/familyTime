# FamilyTime

Rodinný plánovač, který pomáhá celé domácnosti lépe fungovat. FamilyTime je jednoduchá aplikace pro plánování aktivit, úkolů, odpovědností a společných termínů v jedné přehledné stránce.

Výhodou je, že je vhodná pro rodiny, kteří chtějí mít vše na jednom místě: kdy kdo má školu, sport, práci, návštěvy, domácí úkoly, narozeniny, výlety i běžné povinnosti. Aplikace je navržena tak, aby byla přehledná, rychlá a snadno použitelná i pro lidi, kteří nechtějí složité nástroje.

## Proč je FamilyTime užitečná?

Většina rodin řeší stejný problém: informace jsou roztroušené v mobilu, kalendáři, poznámkách, chatových skupinách a papírových listech. FamilyTime to sjednocuje do jednoho místa.

Díky tomu:

- víte, co se děje každý den,
- nemusíte si všichni pamatovat všechny termíny,
- snadno sdílíte úkoly a odpovědnosti,
- méně se zapomíná na důležité věci,
- domácnost funguje hladceji a s méně stresu.

## K čemu je dobrá?

FamilyTime je ideální pro:

- rodiny s dětmi a mnoha aktivitami,
- partnery, kteří plánují společný kalendář,
- domácnosti, kde se dělí povinnosti,
- starší rodiče, kteří chtějí mít přehled o plánování,
- každého, kdo chce mít nejdůležitější informace o rodině vždy po ruce.

Aplikace je skvělá pro běžný život: schůzky, sport, školní akce, návštěvy, úklid, nákupy, vaření, dovolené, narozeniny, oslavy nebo jen jednoduché přehledy o tom, co se v domácnosti chystá.

## Co umí?

### Společný rodinný kalendář
- plánování aktivit a událostí,
- přehled dnů, týdnů a konkrétních časů,
- snadné přidávání a úpravování plánů,
- zobrazení toho, co je naplánované právě dnes.

### Úkoly a odpovědnosti
- přidávání domácích úkolů,
- přiřazení konkrétní osobě,
- označení splněných úloh,
- přehled, kdo má na co odpovědnost.

### Rodinné sdílení
- vytvoření vlastní domácnosti,
- pozvánky pro členy rodiny,
- přístup jen pro oprávněné osoby,
- rozdělení rolí správce a člena.

### Připomínky a upozornění
- notifikace před blížícím se termínem,
- připomínání důležitých událostí,
- jednoduché upozornění, aniž byste museli aplikaci neustále kontrolovat.

### Flexibilita a dostupnost
- přístup z prohlížeče,
- instalace na telefon nebo tablet jako aplikace,
- práce i offline s lokální kopií dat,
- synchronizace mezi členy domácnosti.

## Jak aplikaci používat v praxi?

### 1. Vytvořte domácnost
Při prvním spuštění vytvoříte rodinu nebo domácnost, do které se přidají další členové.

### 2. Přidejte členy
Každý člověk může mít svůj vlastní profil a barevné označení, aby bylo jasné, kdo co plánuje.

### 3. Plánujte aktivity
Vložte schůzky, sportovní aktivity, oslavy, pracovní termíny nebo jakékoli důležité události.

### 4. Rozdělte úkoly
Například: kdo uklízí, kdo vaří, kdo se stará o nákupy, kdo má přivézt dítě ze školy.

### 5. Nastavte připomínky
Aplikace vám upozorní, když se blíží událost nebo úkol, takže nic neunikne.

### 6. Všichni mají přehled
Všichni členové rodiny vidí stejný plán, takže není potřeba opakovaně vysvětlovat nebo hledat informace ve zprávách.

## Pro koho je FamilyTime skvělá?

- pro rodiny, které chtějí méně chaosu,
- pro rodiče s rozvrhem dětí a aktivit,
- pro lidi, kteří rádi plánují společně,
- pro domácnosti, kde se dělí odpovědnosti,
- pro každého, kdo chce mít rodinný život více uspořádaný.

## Výhoda oproti běžným nástrojům

FamilyTime není jen kalendář. Je to jednoduchý rodinný organizér, který spojuje plánování, úkoly a sdílení do jednoho místa.

Na rozdíl od roztroušených poznámek, chatů nebo různých aplikací:

- je vše na jednom místě,
- je to přehledné a srozumitelné,
- nevyžaduje složitou instalaci,
- funguje i pro běžné rodiny bez technických znalostí,
- pomáhá udržovat domácnost v pořádku bez stresu.

## Rychlý start

Požadovaný je Node.js 18 nebo novější.

```bash
npm start
```

Aplikace bude dostupná na http://localhost:3000.

## Proč by si lidé měli FamilyTime vyzkoušet?

Protože rodinný život je jednodušší, když je vše přehledné. FamilyTime pomáhá vyřešit každodenní chaos, který vzniká z neorganizovaných plánů, zapomenutých termínů a nevyjasněných povinností.

Jde o praktický nástroj, který sice neřeší celý život, ale výrazně usnadňuje organizaci a udržuje domácnost v klidu.

## Rozvoj a technické informace

Pro vývojáře a správce je aplikace postavená na Node.js, JavaScriptu, HTML a CSS bez nutnosti externích balíčků. Obsahuje také funkce jako synchronizace, lokální zálohy, iCalendar export, offline provoz a instalaci jako PWA.

### Spuštění

```bash
npm start
```

### Testy

```bash
npm run check
npm test
```

### Datové úložiště

Aplikace ukládá data do složky `data/`, která obsahuje údaje o domácnosti, účtech a přístupových klíčích.

## Shrnutí

FamilyTime je jednoduchý, přátelský a praktický nástroj pro rodiny, které chtějí mít více klidu, méně chaosu a lepší přehled o všem, co se v jejich domácnosti děje.

Je to aplikace pro skutečný život — pro každodenní plánování, organizaci a sdílení odpovědnosti mezi členy rodiny.
